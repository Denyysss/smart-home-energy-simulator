# ⚡ ЕнергіяДім — Симулятор споживання електроенергії побутовими приладами

Веб-додаток для моделювання, аналізу та автоматичної оптимізації добового споживання електроенергії в будинку чи квартирі за двозонним тарифом.

## 🚀 Основні можливості

- **Каталог та керування приладами**: додавання, редагування, увімкнення/вимкнення побутових приладів з урахуванням циклічності роботи (`duty_cycle`, наприклад для холодильника чи пральної машини).
- **Погодинна симуляція на 24 години**: розрахунок навантаження (Вт), споживання (кВт·год) та вартості (грн) за денним (`07:00–23:00`) і нічним (`23:00–07:00`) тарифами.
- **Контроль ліміту автомата**: автоматичне виявлення годин перевантаження електромережі (`В × А`).
- **✨ Розумний оптимізатор розкладу (`/api/optimize`)**: в 1 клік переносить гнучкі потужні прилади (бойлер, пральна машина, посудомийна машина, зарядка авто) у нічну зону без перевантажень автомата та показує економію за місяць.
- **Керування кількома будинками**: повноцінне збереження будинків, тарифів і приладів у базі даних SQLite через SQLAlchemy ORM.
- **Графіки та аналітика (Chart.js)**: погодинне споживання, вартість, внесок кожного приладу (stacked bar), порівняння тарифів, прогноз на місяць/рік та еко-показники CO₂.

## 🛠️ Технологічний стек

- **Backend**: Python, FastAPI, SQLAlchemy, Pydantic, Uvicorn
- **Database**: SQLite (`energy.db`)
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, Chart.js
- **Tests**: Pytest, HTTPX (`11 автотестів`)

## 📦 Структура проєкту

```text
smart-home-energy-simulator/
├── backend/
│   ├── main.py              # FastAPI сервер та REST API ендпоінти
│   ├── simulation.py        # Математичне ядро симуляції та оптимізації розкладу
│   ├── database.py          # SQLAlchemy моделі (Каталог, Будинки, Прилади) + Seed
│   ├── test_simulation.py   # Юніт- та інтеграційні автотести (pytest)
│   └── requirements.txt     # Python-залежності
└── frontend/
    ├── index.html           # Інтерфейс дашборду (SPA)
    ├── styles.css           # Темна тема та адаптивні стилі
    └── script.js            # Логіка клієнта, робота з API та Chart.js
```

## ▶️ Як запустити локально

1. **Встановіть залежності та запустіть Backend**:
   ```bash
   cd backend
   pip install -r requirements.txt
   python -m uvicorn main:app --reload --port 8000
   ```
2. **Відкрийте сайт у браузері**:
   - Перейдіть за адресою: **http://localhost:8000** (бекенд автоматично роздає фронтенд)
   - Swagger документація API: **http://localhost:8000/docs**

3. **Запуск автотестів**:
   ```bash
   cd backend
   python -m pytest -v
   ```
